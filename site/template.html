安装

装进你的 AI 工具

只是想体验，直接在网页里用，无需安装、无需注册。想在自己的 Claude 或 Gemini 里随时问，下载对应祖师的技能包上传即可。

  1. 在上方祖师卡片点「下载技能包」，得到一个 .zip 文件（不用解压）。
  2. Claude（claude.ai，免费版也可）：设置 → 功能（Capabilities），打开「代码执行与文件创建」；再到 自定义（Customize）→ 技能（Skills）→「+」→ 上传技能，选这个 .zip。
  3. Gemini（gemini.google.com，个人账号）：自定义（Customize）→ 技能（Skills）→ 创建 → 上传，选这个 .zip。
  4. 之后在对话里问相关问题（如「怎么参话头」），它会自动以这位祖师的教法作答并附出处；手机 App 登录同一账号也能用。

网页版里技能不能联网，只依据包内已核对的原典摘录作答；要实时检索全藏，用下面的终端安装或 fojin.app。多祖师对比、辩论、学修路径三种模式目前只在终端可用。

# 一次装全部 21 个技能
npx master-skill install --all
# 不知道该问谁？让它推荐
npx master-skill recommend "念佛怎么念才算老实"

装好后在对话里直接输入 /master-huineng、/compare-masters 等。

codex plugin marketplace add xr843/Master-skill && codex plugin add master-skill@master-skill
# skills.sh：可装进 Claude Code、Codex、Cursor、Gemini 等。必须带 --full-depth
npx skills add xr843/Master-skill --full-depth

各工具的详细步骤见 安装文档。

装好后还能用：/compare-masters 多祖师并列对比 · /master-debate 祖师辩论 · /master-curriculum 学修路径 · /master-help 我该问谁 · /create-master 自定义祖师
